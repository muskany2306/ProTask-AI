# 🚀 ProTask AI

A full-stack task management app with authentication and productivity dashboard.

## 🔥 Features
- User Signup/Login
- JWT Authentication
- Task CRUD (Create, Read, Update, Delete)
- Pending & Completed tasks tracking
- Responsive UI

## 🛠 Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- JWT
